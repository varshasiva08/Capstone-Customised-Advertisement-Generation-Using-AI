# LEGACY - do not use for reported results

These scripts score images with LLaVA/phi3 via Ollama. They are kept only so
earlier numbers can be traced. They are NOT valid evidence: the scorer saw the
target (leakage), self-reported confidence, had no pass threshold, and the same
model family drove and graded the loop.

Use `eval/run_experiment.py` (DeepFace verifier, human ground truth) instead.
